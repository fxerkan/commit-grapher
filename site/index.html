One place for everything

Three ways to see your work

Connect an account and the first thing you see is the graph. Then drill anywhere.

🕸️

Network graph

Accounts → repos → branches → PRs → commits as an Obsidian-style WebGL graph. Physics, zoom, drag, focus, and deep filtering across every dimension.

🟩

Contribution heatmap

A GitHub-style calendar combined across every provider. Click any day to drill into a real git-graph — branch & merge lanes, avatars, clickable commits.

📊

Charts & stats

Commits over time, top repositories, authors, pull-request states — with cross-filtering, so one click reshapes every view.

🔌

Multi-provider

GitHub and Azure DevOps today; GitLab, Bitbucket, Gitea and Codeberg on the same adapter interface. Public usernames or private repos with a token.

💻

Local-first

Runs on your machine on a local port. No account, no cloud, no telemetry. Tokens live in your OS keychain, never on disk.

🧠

Filter like a pro

Provider, organization, workspace, repo, branch, PR, author — cascaded, searchable, multi-select. Tell humans from AI agents, or show only your own activity.

🔒

Your code never leaves your machine

commit-grapher reads only metadata — commit messages, branch names, PR titles, timestamps — through each provider's REST API. It never clones a repository or reads a single line of source.
