A tour of every page

What each screen does, and how to drive it.

The flagship

🕸️ Network Graph

A physics-driven map of your entire git footprint. Node colours: account, repo, branch, PR, commit.

  • Drag nodes, scroll to zoom, hover to light up a node's neighbourhood.
  • Click a repo to focus/drill in; click the background to reset.
  • Filter by provider, account, org, workspace, repo, branch, PR, author, tag.
  • Human vs AI toggle and Only my activity to cut the noise.
Consistency, at a glance

🟩 Contribution Heatmap

  • The familiar year calendar — but merged across all providers at once.
  • Pick any year; click a day to expand its commits as a git-graph.
  • Branch/merge lanes with clickable commit links.

Connect an account

Three steps, then everything lights up.

  1. Open the app → Accounts tab → pick your provider.
  2. Paste a Personal Access Token (or use GitHub OAuth). Tokens go straight to your OS keychain.
  3. Hit Sync — then explore the Graph, Heatmap, Stats and Contributors.

Run it locally

Python ≥ 3.13 backend, Vite/React frontend. Local-first — nothing to deploy.

# backend
python -m venv .venv && source .venv/bin/activate
pip install -e backend
uvicorn app.main:app --app-dir backend --reload    # http://localhost:8000

# frontend (dev, hot reload)
cd frontend && npm install && npm run dev           # http://localhost:5173
# ...or build once and let the backend serve it:
cd frontend && npm run build

🔒 Privacy, plainly

Metadata only

Commits, branches, PRs, tags, repo stats. It never clones a repo or reads file contents.

Keychain tokens

PATs live in your OS keychain via keyring — never on disk, never logged, never committed.

Local-first

Runs on your machine and talks straight to the providers. No middleman, no telemetry.
